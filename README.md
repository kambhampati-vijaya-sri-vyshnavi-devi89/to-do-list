# Todo List App

A simple and elegant **Todo List App** with a modern UI, animations, and local storage support. Built with **HTML, CSS, and JavaScript**.

## Features
- 📌 **Add, complete, and remove todos** easily
- 🎨 **Beautiful UI** with smooth animations
- 🌎 **Dynamic background image** (Auto-refresh from Unsplash)
- 💾 **Saves todos in localStorage** (Persists across refreshes)
- 📱 **Responsive design** (Works on mobile & desktop)

## Setup Instructions
### 1️⃣ Clone the Repository
```bash
git clone https://github.com/your-username/todo-list.git
cd todo-list
```
### 2️⃣ Open in Browser
Simply open `index.html` in any modern browser.

### 3️⃣ Customize Background
To change the background image, update this line in **style.css**:
```css
body {
  background: url('https://source.unsplash.com/1920x1080/?nature,abstract') no-repeat center center/cover;
}
```
Replace `nature,abstract` with keywords like `city,night`, `minimalist`, etc.
